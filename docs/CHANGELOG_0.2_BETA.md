# Everis 0.2-beta

Android 12 и новее · ARM64 · сборка 10.

## Исправления в последней сборке

- Исправлена загрузка студенческого расписания ДГТУ: общие занятия с нулевым кодом группы больше не приводят к отклонению всего ответа. Принадлежность расписания по-прежнему проверяется по метаданным и названию группы.
- Подгруппы ДГТУ распознаются как из отдельного поля, так и из пометки «п/г 1»/«п/г 2» в названии занятия. Они доступны при выборе группы и учитываются в фильтрации и статистике.
- Убрана дополнительная вспышка при нажатии на док. Выделение показывает одна перемещающаяся капсула.
- Подсказки групп сохраняют высоту и не закрываются между символами. Поле ввода больше не прыгает при обновлении результатов, в том числе с открытой клавиатурой.
- Исправлено чёрное мигание при первой смене языка. Интерфейс обновляется в текущем окне с плавным размытием; текст сообщения не меняется во время перехода. Убрано лишнее копирование экрана в изображение.
- Заголовки настроек, их подразделов и страницы «О приложении» закреплены над прокручиваемым содержимым.

## Новое по сравнению с 0.1-beta

- Добавлены открытые каталоги групп и расписания студентов и преподавателей ДГТУ. Вуз выбирается при настройке группы; неподтверждённые даты и сведения не выдумываются.
- Добавлены поиск преподавателя и просмотр его расписания по дням. Используется вуз сохранённой группы, без отдельного переключателя; каталог и расписания сохраняются для работы офлайн.
- Для РГЭУ (РИНХ) добавлен справочник полных ФИО из официальных страниц вуза. Неоднозначные сокращения сохраняются в исходном виде.
- Добавлен компактный плавающий док с цельным перемещающимся выделением. В оформлении можно вернуть классическую нижнюю панель; новый вид включён по умолчанию.
- Долгое нажатие на активную вкладку возвращает к главному экрану именно этого раздела, сохраняя состояние остальных разделов.
- Восстановлен последовательный возврат назад: закрытие окна, выход из подпункта, переход с основного экрана раздела на «Главную». Из корня «Главной» — системный выход.
- При записи задания на следующее занятие можно фильтровать пары по типу: лекция, практика или лабораторная.
- Ускорена подготовка дисциплин; у вложенного списка занятий появились подсказка и индикатор прокрутки.
- Исправлена форма крайних дней недельного переключателя. Барабаны времени получили инерцию и плавное доведение до значения.
- Исправлены зависание пунктов после смены вида дока и восстановление преподавателя от прежнего вуза. Улучшены обработка быстрых переключений и согласованность публичных кэшей.
- Сохранена совместимость резервных копий РИНХ. Данные ДГТУ используют новый номер переносимого формата, чтобы прежняя версия приложения не открывала их как расписание другого вуза.

## Проверки

Пройдены 136 тестов приложения и 83 проверки логики, сети и защиты данных — всего 219. Debug и Release Lint без ошибок. Проверены реальные ответы ДГТУ, выбор и фильтрация подгрупп, неподвижность поиска и заголовков, быстрая навигация. На контрольной записи первой смены языка чёрных кадров не обнаружено.

## Ограничения

Полнота и актуальность расписания зависят от публичных сайтов вузов. Android может задерживать фоновые проверки. Неоднозначные ФИО не угадываются. Репозиторий пока приватный: просмотр и скачивание требуют доступа к GitHub; анонимная автоматическая проверка обновлений такого репозитория недоступна. Токены в приложение не встроены.

## English

Everis 0.2-beta adds DSTU student and teacher timetables, offline teacher search, a compact floating navigation dock with a classic alternative, section-root shortcuts, hierarchical Back navigation, class-type filters for homework, clearer discipline lists and inertial time wheels.

Build 10 fixes DSTU shared classes and subgroup labels, removes the extra dock press flash, stabilizes group suggestions, eliminates the first language-change blackout and keeps Settings/About headings fixed while scrolling. It passed 219 tests/checks and Debug/Release Lint. Public timetable completeness depends on the universities. This repository remains private; downloads require repository access, and anonymous in-app release checks are unavailable. No access token is included in the APK.
